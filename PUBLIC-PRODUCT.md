# Public B2B productisation

This build is no longer tied to the original reference company.

## What changed

- Product identity moved to `src/config/product.ts`.
- App/workspace/demo-user identity can be overridden through `.env.local`.
- Visual system changed to a neutral B2B product theme.
- External-font dependency assumptions were removed in favor of a readable system font stack.
- Demo records now cover multiple fictional B2B industries.
- Currency, locale and timezone presentation are configurable.
- Customer-specific wording and company examples were removed from UI, docs and API examples.

## Intended positioning

A focused CRM for B2B teams that need account context, stakeholders, opportunity pipeline, lightweight delivery/project context, follow-up tasks, activity history and auditability without the feature weight of large CRM suites.
